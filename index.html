Step 03 — Collaborative Filtering

Matrix Factorization

Break the giant matrix into two smaller ones. Each user and song becomes a vector in "taste space." Adjust the embedding dimension to see the tradeoff.

Core idea: Instead of storing the full R matrix (600M × 100M), find matrices U (600M × k) and I (k × 100M) where R ≈ U × I. The value of k (latent dimensions) controls accuracy vs. cost.

Step 04 — Embedding Space

Taste Space Visualized

Users and songs as points in 2D space. Similar items cluster together. Drag the user point to see which songs are nearest — those become recommendations.

In reality: This space has 128-512 dimensions. We project to 2D for visualization. The dot product between a user vector and song vector predicts how much they'll like it. Closer = better match.

Step 07 — The Fusion Layer

Combining Three Signals

Adjust the weight of each pillar. Watch how the final recommendation list changes in real-time. This is the core of Spotify's recommendation engine.

Formula: Score = λ₁ × Collab + λ₂ × Audio + λ₃ × NLP. Each pillar covers the weaknesses of the others. Collaborative filtering fails for new songs; audio analysis doesn't understand culture; NLP requires internet discussion to exist.
